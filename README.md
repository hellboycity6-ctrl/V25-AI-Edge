# V25 AI Analyzer

Mobile-friendly V25 (1s) market-analysis prototype.

## GitHub Pages

This repository is configured to deploy automatically to GitHub Pages using GitHub Actions.

After pushing to `main`, open the repository's **Settings → Pages** and select **GitHub Actions** as the source if GitHub has not already enabled it.

The site will normally be available at:

`https://YOUR-GITHUB-USERNAME.github.io/v25-ai-analyzer/`

GitHub Pages can host static HTML/CSS/JavaScript directly from a repository. See the official documentation:
https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
